# Employee-Tracker

## Description

This is an employee tracker used to check on a database of departments, roles, and employees.

## Table of Contents

    Installation
    Usage
    Credits
    License

## Installation

To install dependencies, run the following command: `npm i, npm run build`

## Usage

To use this application, fork the repository, open an integrated terminal in the db folder, run `psql -U (username)`, enter your password, run `\i schema.sql, \i seeds.sql`
Once the database is seeded, you can open a terminal in the main folder, and run `npm run start`
